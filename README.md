# อัปเดตเซิร์ฟเวอร์กลาง v2: บัญชี + แอดมินที่เซิร์ฟเวอร์ + เซฟตัวละครบนเซิร์ฟเวอร์
(ชุดนี้รวมของรอบแรกไว้แล้ว ใช้ทับได้เลยแม้ยังไม่เคยลงรอบแรก)

## 1) Turso (ถ้ายังไม่ได้ทำ)
สมัคร turso.tech > สร้างฐานข้อมูล > คัดลอก Database URL (`libsql://...`) และสร้าง Auth Token
ตารางทั้งหมด (`users`, `sessions`, `characters`) เซิร์ฟเวอร์สร้าง/อัปเกรดให้เองตอนสตาร์ท

## 2) เซิร์ฟเวอร์บน Render
เอาไฟล์ใน `zombie-relay/` ไปทับใน repo เดิมแล้ว push จากนั้นตั้ง Environment:

| ชื่อ | ค่า | จำเป็น |
|---|---|---|
| `TURSO_DATABASE_URL` | URL จาก Turso | ใช่ |
| `TURSO_AUTH_TOKEN` | token จาก Turso | ใช่ |
| `ADMIN_USERNAME` | ชื่อบัญชีแอดมิน เช่น `Texz` (3-16 ตัว) | ถ้าต้องการแอดมิน |
| `ADMIN_PASSWORD` | รหัสผ่านบัญชีแอดมิน 8-64 ตัว | ถ้าต้องการแอดมิน |
| `ADMIN_PASSCODE` | รหัสปลดล็อกแผงแอดมิน (เว้นว่าง = ไม่ต้องกรอก) | ไม่บังคับ |

- เซิร์ฟเวอร์สร้างบัญชีแอดมินให้เองตอนสตาร์ท แล้วเข้าเกมด้วยชื่อ/รหัสนั้นตามปกติ (ไม่ต้องสมัครในเกม และไม่มีใครสมัครชื่อนี้ตัดหน้าได้)
- แอดมินมีได้บัญชีเดียวตาม `ADMIN_USERNAME` ถ้าเปลี่ยนค่านี้ แอดมินคนเก่าจะถูกถอดสิทธิ์
- เปลี่ยน `ADMIN_PASSWORD` ใน Environment = เปลี่ยนรหัสแอดมินและล้างเซสชันเก่า
- **ใช้รหัสใหม่เท่านั้น** รหัสแอดมินเก่าเคยอยู่ในไฟล์เกม ถือว่าเปิดเผยแล้ว
- ดู Logs ต้องเห็น `สร้างบัญชีแอดมิน: ...` และไม่มี `[warn]`

## 3) เกม (Godot) — คัดลอกทับตามพาธเดิม
- `core/accounts.gd`    ล็อกอิน/สมัคร, สิทธิ์แอดมิน, ดึงตัวละคร จากเซิร์ฟเวอร์
- `core/config.gd`      ลบ `ADMIN_USERNAME` และ `ADMIN_PASSCODE` ออกจากไฟล์เกม (เหลือแค่คอมเมนต์)
- `core/main.gd`        ดึงตัวละครก่อนเข้าห้อง / เซฟขึ้นเซิร์ฟเวอร์ / จัดการถูกเตะ
- `net/net_client.gd`   ส่ง token, `save_char()`, สัญญาณ `kicked`
- `ui/game_menu.gd`     ปุ่มล็อกอิน/สมัครรอเซิร์ฟเวอร์ได้
- `ui/admin_panel.gd`   ตรวจรหัสปลดล็อกแผงที่เซิร์ฟเวอร์

## พฤติกรรมใหม่
- เซฟตัวละครออนไลน์ 1 บัญชี = 1 ตัวละคร เก็บบนเซิร์ฟเวอร์ เล่นเครื่องไหนก็ได้ตัวเดิม (เซฟเกมเดี่ยวยังอยู่ในเครื่องเหมือนเดิม)
- ตัวละครออนไลน์เก่าในเครื่อง (`user://online_char.json`) ไม่ถูกย้ายขึ้นเซิร์ฟเวอร์ ผู้เล่นจะเริ่มตัวละครใหม่
- โหลดตัวละครจากเซิร์ฟเวอร์ไม่สำเร็จ = ไม่ให้เข้าห้อง (กันเริ่มตัวละครใหม่ไปเซฟทับของเดิม)
- บัญชีเดียวออนไลน์ได้ที่เดียว: เข้าห้องจากเครื่องใหม่ เครื่องเก่าจะถูกเตะออก (กันเซฟทับกัน/เอาของซ้ำ)
- ตายแล้วเซิร์ฟเวอร์ล้างตัวละครเหมือนเดิม (เหลือแค่จำแมพ)
- เซิร์ฟเวอร์เขียนเซฟไม่เกินราว 1 ครั้ง/วินาทีต่อคน ตัวละครใหญ่สุด 48 KB
- เกมเวอร์ชันเก่าเข้าห้องไม่ได้ ต้องอัปเดตทุกคน

## ข้อจำกัดที่ควรรู้
- สิทธิ์แอดมินและรหัสปลดล็อกตัดสินที่เซิร์ฟเวอร์แล้ว แต่ฟังก์ชันในแผงแอดมินยังทำงานในเครื่องผู้เล่น (เกมนี้โฮสต์เป็นคนตัดสินสถานะโลก) คนที่แก้ไฟล์เกมเองยังข้ามหน้าต่างแอดมินในเครื่องตัวเองได้ แต่ไม่ได้สิทธิ์ใหม่จากเซิร์ฟเวอร์ และไม่รู้รหัส
- เซฟตัวละครบนเซิร์ฟเวอร์กันการแก้ไฟล์เซฟในเครื่อง แต่ไม่กันเกมที่ถูกแก้แล้วส่งข้อมูลตัวละครปลอมขึ้นไป ถ้าจะกันจริงต้องให้เซิร์ฟเวอร์ตรวจค่าสมเหตุสมผล (เช่น จำนวนของ/เลเวลต่อเวลาที่เล่น) ซึ่งต้องรู้กติกาเกมเพิ่ม
